# Math error taxonomy

Categories for wrong answers, with the written-answer signature of each.

- **borrowing-slip** — Subtraction needed regrouping and it was skipped or
  done halfway. Signature: smaller-from-larger in a column (52 − 27 → 35),
  or off by exactly 10/100 from the correct answer.
- **regrouping-carry-slip** — Addition carry forgotten or added twice.
  Signature: off by exactly 10/100, or the carried digit appears in the
  answer twice.
- **place-value** — Digits landed in the wrong column or a number was read
  at the wrong scale. Signature: answer is 10×/÷10 the correct one, or
  digits shifted one place.
- **operation-choice** — The wrong operation was used (added instead of
  multiplied, subtracted instead of divided). Signature: answer equals the
  result of a different plausible operation on the same numbers.
- **fact-recall** — A basic fact (times table, number bond) was wrong while
  the method was right. Signature: close to correct, one fact off
  (7 × 8 → 54).
- **incomplete-two-step** — A two-step problem stopped after the first
  step. Signature: answer equals the intermediate result.
- **digit-slip** — Digits reversed, copied wrong, or a number misread from
  the question. Signature: answer's digits are a rearrangement of the
  correct digits, or uses a number that differs from the question by one
  digit.
- **units** — Right value, wrong or missing unit where the key requires
  one (cm vs m, cents vs dollars).
- **unexplained** — The written answer gives no reliable clue about the
  cause.
